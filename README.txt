NOVA PLANNER 1.0 – iPhone-Web-App

INSTALLATION über GitHub Pages:
1. Auf github.com ein kostenloses Konto nutzen oder anmelden.
2. Neues öffentliches Repository "nova-planner" erstellen. Achtung: Dateien dort sind öffentlich, keine Geheimnisse hochladen!
3. Vier Dateien aus diesem ZIP hochladen: index.html, icon.svg, manifest.webmanifest, sw.js.
4. Repository > Settings > Pages > Source: Deploy from a branch > Branch: main / (root) > Save.
5. Auf dem iPhone die angezeigte HTTPS-Website mit Safari öffnen.
6. Safari > Teilen > Zum Home-Bildschirm > Als Web-App öffnen > Hinzufügen.

Die Aufgaben werden zunächst ausschließlich lokal im Browser dieses iPhones gespeichert. GitHub Pages veröffentlicht NUR den App-Code, nicht deine Aufgaben. Pod-Synchronisierung ist noch nicht implementiert.
